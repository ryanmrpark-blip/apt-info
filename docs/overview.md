# 프로젝트 개요: apt-info

## 1. 프로젝트 목적
- **아파트 실거래가 및 부동산 정보** 수집, 가공, 탐색적 데이터 분석(EDA)
- 지역별, 연도별, 면적별 매매/전월세 실거래가 추이 및 가격 형성 요인 분석
- 이상치 탐지 및 시각화 리포트/대시보드 구축을 통한 부동산 시장 통찰 확보

## 2. 디렉토리 구조
```text
apt-info/
├── .venv/                     # uv 기반 파이썬 가상환경
├── data/
│   ├── raw/                   # 원본 데이터 수집 저장소 (국토부 실거래가 등)
│   └── processed/             # 가공 및 정제된 데이터셋
├── docs/
│   ├── overview.md            # 프로젝트 개요 및 명세서
│   └── plan.md                # 단계별 진행 계획 및 마일스톤
├── reports/
│   ├── figures/               # EDA 시각화 차트 및 이미지
│   └── report.md              # 분석 및 대시보드 결과 보고서
├── src/
│   ├── __init__.py            # 소스 패키지 초기화
│   ├── utils.py               # 공통 보조 함수 및 데이터 입출력 유틸리티
│   └── main.py                # 실행 진입점 메인 스크립트
├── tests/
│   ├── __init__.py            # 테스트 패키지 초기화
│   └── test_utils.py          # 단위 테스트 스크립트
├── pyproject.toml             # uv 패키지 및 의존성 설정
├── README.md                  # 프로젝트 안내 문서
└── .gitignore                 # 형상 관리 제외 설정
```

## 3. 작업 원칙
- **가상환경**: Python 가상환경은 항상 `uv`만 사용 (`.venv`)
- **경로 관리**: 모든 파일 참조 및 입출력은 프로젝트 루트 기준 **상대 경로** 사용
- **코드 문서화**: 모든 Python 코드는 한국어 Docstring(Google Style)과 명확한 타입 힌트 필수 적용
- **데이터 보존**: 대용량 원본 및 가공 데이터는 Git 추적에서 제외(`data/` 하위 `.gitkeep` 유지)
