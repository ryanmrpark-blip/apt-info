# 프로젝트 계획서: apt-info

## 1. 개요
본 문서는 아파트 실거래가 및 부동산 데이터 분석(EDA) 프로젝트의 단계별 추진 계획 및 실행 마일스톤을 기술합니다.

## 2. 단계별 마일스톤

### 1단계: 개발 환경 구성 및 스캐폴딩 (Phase 1)
- [x] 프로젝트 워크스페이스 디렉토리 및 표준 폴더 구조 생성 (`data`, `docs`, `reports`, `src`, `tests`)
- [x] uv 기반 가상환경(`.venv`) 초기화 및 `pyproject.toml` 환경 설정
- [x] 공통 유틸리티 모듈(`src/utils.py`) 및 메인 진입점(`src/main.py`) 구현
- [x] 단위 테스트 작성 및 가상환경 실행 검증

### 2단계: 데이터 수집 및 전처리 (Phase 2)
- [ ] 데이터 소스 선정 (국토교통부 실거래가 공개시스템 Open API, 공공데이터포털, KB부동산, 아실 등)
- [ ] 원본 데이터셋 다운로드/수집 모듈 개발 및 `data/raw/` 저장
- [ ] 데이터 정제: 결측치/이상치 처리, 날짜/가격/전용면적 타입 변환, 평당 가격 계산 등 파생변수 생성
- [ ] 정제된 데이터셋 `data/processed/` 저장 (Parquet 또는 CSV)

### 3단계: 탐색적 데이터 분석 (EDA) 및 시각화 (Phase 3)
- [ ] 지역별(시도/구군/동별) 매매/전세 가격 분포 및 거래량 추이 분석
- [ ] 전용면적별, 건축연한별(신축/구축) 가격 상관관계 분석
- [ ] 시계열 가격 변동률 및 신고가/급매 거래 패턴 탐색
- [ ] 시각화 차트 생성 및 `reports/figures/` 저장

### 4단계: 분석 보고서 및 대시보드 구축 (Phase 4)
- [ ] 종합 분석 결과 보고서(`reports/report.md`) 작성
- [ ] 대화형 인터랙티브 대시보드(정적 HTML 또는 대시보드 앱) 설계 및 구축
- [ ] 사용자 요구사항 반영 및 최종 검증
