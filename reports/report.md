# 분석 및 대시보드 결과 보고서: apt-info

## 1. 개요
본 문서는 `apt-info` 프로젝트의 국토교통부 아파트 매매 실거래가 수집 파이프라인과 DuckDB 인메모리 OLAP 엔진을 통해 수집·분석된 최근 실거래가 데이터의 종합 분석 보고서입니다. 본 시스템은 매일 GitHub Actions를 통해 최신 데이터를 자동 갱신하며, Streamlit 반응형 웹 대시보드로 실시간 시각화 서비스를 제공합니다.

- **수집 시점**: 2026년 10월 4일 기준

## 5. 결론 및 인사이트

1. **강남·서초 한강변 초고가 거래 주도**:
   - 상위 거래금액 TOP 5가 모두 서울 서초구 및 강남구 한강변 핵심 단지(래미안원베일리, 신반포2차, 아크로리버파크, 청담자이)에 집중되어 있습니다.
   - 특히 평당 1,600만 ~ 1,700만 원(3.3㎡당)을 상회하는 재건축 및 신축 하이엔드 단지 수요가 지속되고 있습니다.
2. **데이터 파이프라인의 실시간성 확보**:
   - `sqlite` (마스터 DB 영구 보존)와 `parquet` (최근 7일 경량 배포)의 2중 저장 전략을 통해 GitHub 저장소 용량 제한을 준수하면서도 빠른 서빙 속도를 달성했습니다.
   - DuckDB 쿼리 엔진은 503건 기준 모든 KPI 집계 및 필터링을 10ms 이내에 처리하여 Streamlit UI의 매끄러운 반응성을 보장합니다.
3. **향후 확장 방향**:
   - 30일/90일 누적 거래량 이동평균 지표 추가
   - 국토교통부 아파트 전월세 Open API 연계를 통한 전세가율 비교 분석
   - 카카오맵 API 또는 Folium 지도 기반의 시군구별 히트맵 렌더링
